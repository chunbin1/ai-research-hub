# 名家持仓 13F Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有研报站旁增加 `/whales`，用 SEC 13F 展示六家机构的最新持仓，以及相对上一报告期的增减。

**Architecture:** 纯函数负责解析、选期、美元换算、diff 和 ticker 匹配；SQLite 只存申报和持仓；同步任务串行打 SEC，读接口在查询时做对比。页面与 `/holdings` 分开，开关与信号 cron 同一风格。

**Tech Stack:** Fastify、better-sqlite3、node-cron、React 19、Vite、react-router、node:test、vitest。

## Global Constraints

- 数据源只有 SEC：`data.sec.gov` 的 submissions，`www.sec.gov/Archives` 的信息表 XML，`www.sec.gov/files/company_tickers.json` 的公司名。不接 OpenFIGI / Yahoo
- `WHALES=off` 关闭路由（404 `{ "error": "whales_disabled" }`）和 cron。未设置或其它值表示开启
- User-Agent：`SEC_USER_AGENT` 优先，否则用 `WHALES_CONTACT_EMAIL` 拼 `ai-research-hub whales-13f (<email>)`。都没有则跳过拉取，不把空 UA 打出去
- 请求串行，间隔至少 150ms。429/503 等 1 秒重试一次
- 2023-01-03 及之后提交的 13F，`value` 已是美元；更早的 `value × 1000`。页面写「市值（美元）」
- 增减在读时用相邻两期计算，不建增减表。比较股数
- 映射不上 ticker 时显示 `nameOfIssuer` + CUSIP，不猜测 A/B 股
- 没有 13F 的机构仍出现在列表，状态「暂无数据」
- 不改 holdings 的表、上传协议和「无数据则回首页」的行为
- 测试不访问真实 SEC。`pnpm typecheck`、`pnpm test`、`pnpm build:client` 必须通过
- 种子 CIK（10 位）：伯克希尔 `0001067983`，喜马拉雅 `0001709323`，HHLR `0001762304`，潘兴 `0001336528`，Scion `0001649339`，ARK `0001697748`

设计说明：`docs/superpowers/specs/2026-10-27-whales-13f-design.md`。

**Interfaces:**

- Produces:
  - `valueUnitForFilingDate(filingDate: string): 'dollars' | 'thousands'`
  - `toUsd(reported: number, unit: 'dollars' | 'thousands'): number`
  - `selectReportPeriods(filings: FilingRef[], limit: number): FilingRef[]`

**Interfaces:**

- Consumes: `AggregatedPosition` 的键 `(cusip, putCall, shareType)`
- Produces:
  - `diffPositions(current, previous: AggregatedPosition[] | null): { positions, closed, hasPrevious }`
  - `parseCompanyTickers(text: string): { ticker, title, cik }[]`
  - `matchTicker(rows, issuerName: string): string | null`

`previous === null` 时每行 `change` 为 `null`。空数组表示「有上一份 filing 但没有行」，本期全部算 `new`。股数相同为 `unchanged`，即使市值不同。
