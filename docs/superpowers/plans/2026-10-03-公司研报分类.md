# 公司研报分类实施计划

**Goal:** 研报分「行业 / 公司」两类:上传时选、首页可筛、查重不跨类。

**Spec:** `docs/superpowers/specs/2026-10-03-公司研报分类-design.md`

## Global Constraints

- 注释与用户可见文案一律中文;服务端 import 带 `.js`,测试里 import 被测模块带 `.ts`;
  前端 import 不带扩展名。
- 服务端测试 `node:test` + `assert/strict`;前端 `vitest` + `@testing-library/react`。
- `kind` 在 multipart 里和 `note` 一样**必须排在 file 前面**,服务端流式解析读不到文件之后的字段。
- 新增写接口一律 `requireAdmin`。
- 存量迁移走 `runOnce`,名字上线后不改。
- antd 6:`Alert` 用 `title`;两个汉字的按钮加 `autoInsertSpace={false}`。

## Tasks

### 1. 服务端:类型与推断
- 新增 `services/reportKind.ts`:`ReportKind`、`isReportKind`、`inferKind(title)`;配 `reportKind.test.ts`
  (用两篇真实 H1 + 库里已有的标题当用例)。
- `types.ts` 的 `Document` 加 `kind`。

### 2. 服务端:存储与迁移
- `initDocumentTable` 缺列时 `ALTER TABLE`;`saveDocument` 收可选 `kind`;
  新增 `setDocumentKind`、`backfillDocumentKinds`(`runOnce`);`index.ts` 启动时调用。
- `importRaw` 新登记的行用 `inferKind(filename)`,冲突更新时不动 `kind`。
- 测试:往返、旧库升级(无 `kind` 列的库)、回填只改推得出 `company` 的。
- 依赖 `INSERT INTO documents VALUES (...)` 位置参数的老测试改成带列名。

### 3. 服务端:查重按类型
- `findSimilarReports` 的 `upload` / `existing` 加可选 `kind`;两边都有且不同则整篇排除。
  `topic` 数组与 `existing` 对齐,过滤时同步取子集;主题中位数在同类子集上算。
- 测试:跨类排除、同类不受影响、任一边未知不过滤、库太小时主题关闭。

### 4. 服务端:路由
- `readUpload` 读 `kind` 字段(非法值 400)。
- `POST /documents`:`kind ?? inferKind(title) ?? 'industry'`。
- `POST /documents/similar`:返回 `suggestedKind`;候选按 `up.kind ?? suggestedKind` 过滤。
- `PATCH /documents/:id` `{kind}`:管理员,404 / 400。
- 测试:上传带 / 不带 kind、非法 kind、查重跨类、PATCH 权限与校验。

### 5. 前端:类型、接口、首页
- `types.ts`:`ReportKind`、`Document.kind?`(旧缓存没有,按 `industry`)、`SimilarReport` 不变、
  查重响应加 `suggestedKind`。
- `api.ts`:`uploadDocument(file, kind?)`、`checkSimilar(file, kind?)`、`setDocumentKind`。
- `HomePage`:`?kind=` 筛选、计数、公司小标;管理员的"改类型"(桌面悬停图标 + 移动端底部菜单项)。
- 测试:筛选 / 计数 / 无公司时不出筛选 / 小标 / 改类型。

### 6. 前端:上传弹窗
- `UploadReportModal`:选完文件后,**新建**时显示"研报类型"单选(预填 `suggestedKind ?? industry`);
  作为新版本上传时隐藏(继承原文档)。管理员改选后用新类型重查。
- 测试:预填、改选触发重查、提交带 `kind`、选新版本时不显示。

### 7. 收尾
- README 功能清单加一条;跑 `pnpm typecheck` 与 `pnpm test`(注意 ReaderPage 在 Node 26 的已知红,
  `NODE_OPTIONS=--no-webstorage` 可全绿)。
- 用 preview 在浏览器里走一遍:上传两篇公司研报、筛选、改类型。
