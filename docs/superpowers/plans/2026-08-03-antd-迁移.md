# antd 迁移 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把前端手写的 18 处 emoji 图标和一批原生基础组件迁移到 antd 6,后台四页全面 antd,首页与阅读页只换图标与交互控件、排版配色仍归 Tailwind。

**Architecture:** 先用一个不改任何页面的前置任务把「引入新样式来源」的风险单独隔离并验收;再横切换掉全部图标;之后按页面纵切,风险从低到高逐页迁移。Tailwind 与 antd 通过官方的 CSS `@layer` 排序共存 —— `antd` 层夹在 `base`(preflight)与 `utilities` 之间。

**Tech Stack:** React 19 + Vite + Tailwind v4 + antd 6.5.3 + @ant-design/icons 6.3.2;测试用 vitest + @testing-library/react。

## Global Constraints

- **antd 版本 `^6.5.3`,图标 `^6.3.2`。** peerDependencies 为 `react: >=18.0.0`,**React 19 原生支持,不要安装任何 compat 补丁**(如 `@ant-design/v5-patch-for-react-19`)。
- **前端测试用 vitest**(`import { test, expect, vi } from 'vitest'`)。后端是 node:test,两者不能混。
- **样式硬规则**(本仓库经历过一轮 Tailwind preflight 像素漂移事故,这两条是那次的产物):
  1. **不许就近取整** —— 需要 9px 写 `py-[9px]`,不写 `py-2.5`(那是 10px)。
  2. **不许用 `text-sm` / `text-xs` / `text-2xl` 这类附带隐式行高的字号 utility**,一律写 `text-[14px]` / `text-[12px]` 这类精确任意值。
- 注释与用户可见文案用中文,与现有代码一致。
- **主题用 antd 默认蓝,不传 `theme.token`。** 后台页蓝色系与首页金色点缀的观感断裂是知情选择,不是缺陷。
- **不改 `SpanWaterfall.tsx`、`TraceStats.tsx`** —— 自定义可视化,antd 无对应组件。
- **不换首页报告卡片为 `Card`**,不换骨架屏为 `Skeleton`(现有 `--animate-skeleton` 是上一轮精确复刻迁移前效果的产物)。
- **不引入 antd `Layout` / `Menu`**,不做暗色模式,不移除 Tailwind。
- 每个任务结束前跑一次 `pnpm --filter @arh/client test` 与 `pnpm typecheck`,两者都必须绿。

- [ ] **Step 1: 装依赖**

```bash

```

- [ ] **Step 2: 加 CSS layer 排序**

`packages/client/src/index.css` 第 1 行 `@import "tailwindcss";` **之前**插入一行(这是 antd 官方给 Tailwind v4 的配方):

```css
@layer theme, base, antd, components, utilities;
@import "tailwindcss";
```

排序的作用:`base`(preflight)在 `antd` 之前 → antd 组件样式盖得过 preflight 的 `button { background-color: transparent }`;`utilities` 在 `antd` 之后 → `<Button className="text-[14px]">` 这类 Tailwind 微调仍然生效。两个方向都对。

CSS 规范允许 `@layer` 语句出现在 `@import` 之前,这是合法写法。

- [ ] **Step 3: 套 StyleProvider 与 ConfigProvider**

`packages/client/src/main.tsx` 整体替换为:

```tsx
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { BrowserRouter } from 'react-router-dom'
import { StyleProvider } from '@ant-design/cssinjs'
import { ConfigProvider } from 'antd'
import zhCN from 'antd/locale/zh_CN'
import './index.css'
import App from './App'

const rootEl = document.getElementById('root')
if (!rootEl) throw new Error('Root element #root not found')

createRoot(rootEl).render(
  <StrictMode>
    {/* layer:把 antd 样式注入 @layer antd,配合 index.css 首行的层序,
        让 preflight 盖不住 antd、而 Tailwind utility 仍能盖过 antd */}
    <StyleProvider layer>
      <ConfigProvider locale={zhCN}>
        <BrowserRouter>
          <App />
        </BrowserRouter>
      </ConfigProvider>
    </StyleProvider>
  </StrictMode>,
)
```

**不引入 `antd/dist/reset.css`** —— Tailwind preflight 已经在做重置(`box-sizing`、`margin` 归零、字体栈),两份叠加会互相覆盖。Step 5 会验证 antd 组件在没有它的情况下渲染是否正常。

- [ ] **Step 1: 5 张指标卡换 Statistic**

现在是 5 个手写 div(`min-w-[120px] rounded-xl border border-[#ececec] bg-white px-[22px] py-4`),每个内含一个 24px 数字 + 13px 灰标签。换成 antd `Card` + `Statistic`:

```tsx
import { Card, Statistic } from 'antd'

const metrics = [
  { title: '已评估篇数', value: stats?.docsEvaluated ?? 0 },
  { title: '平均召回率', value: pct(stats?.avgRecall ?? null) },
  { title: '平均精确率', value: pct(stats?.avgPrecision ?? null) },
  { title: '平均忠实度', value: pct(stats?.avgFaithfulness ?? null) },
  { title: '平均相关性', value: pct(stats?.avgRelevancy ?? null) },
]

<div className="mb-6 flex flex-wrap gap-3.5">
  {metrics.map(m => (
    <Card key={m.title} size="small" className="min-w-[120px]">
      <Statistic title={m.title} value={m.value} />
    </Card>
  ))}
</div>
```

注意 `pct()` 返回字符串(`'—'` 或 `'87%'`),所以 `Statistic` 的 `value` 是 string,不要传 `precision`/`suffix`。

- [ ] **Step 2: 8 列手写 table 换 Table**

删掉 `thtd` 常量、整个 `<div className="overflow-x-auto">…</table></div>` 块,以及 `statusClass` 映射(改用 `Tag`)。换成:

```tsx
import { Table, Tag, Button } from 'antd'
import type { ColumnsType } from 'antd/es/table'
import type { EvalReportRow, EvalStatus } from '../types'

const statusTag: Record<EvalStatus, { color: string; label: string }> = {
  none:    { color: 'default',    label: '未评估' },
  running: { color: 'processing', label: '评估中…' },
  done:    { color: 'success',    label: '已完成' },
  failed:  { color: 'error',      label: '失败' },
}

const columns: ColumnsType<EvalReportRow> = [
  {
    title: '报告',
    dataIndex: 'filename',
    render: (v: string, r) => (
      <span
        className={r.status === 'done' ? 'cursor-pointer hover:text-gold' : ''}
        onClick={() => r.status === 'done' && navigate(`/eval/${r.doc_id}`)}
      >{v}</span>
    ),
  },
  { title: '召回', dataIndex: 'avg_recall',       render: pct },
  { title: '精确', dataIndex: 'avg_precision',    render: pct },
  { title: '忠实', dataIndex: 'avg_faithfulness', render: pct },
  { title: '相关', dataIndex: 'avg_relevancy',    render: pct },
  { title: '题数', dataIndex: 'question_count', render: (v: number) => v || '—' },
  {
    title: '状态',
    dataIndex: 'status',
    render: (s: EvalStatus) => <Tag color={statusTag[s].color}>{statusTag[s].label}</Tag>,
  },
  {
    title: '',
    key: 'action',
    render: (_, r) => (
      <Button
        size="small"
        type="primary"
        disabled={r.status === 'running'}
        onClick={() => void runEval(r.doc_id)}
      >{r.status === 'running' ? '评估中…' : '跑评估'}</Button>
    ),
  },
]
```

```tsx
<Table
```

- [ ] **Step 1: 明确改动边界**

- [ ] **Step 2: 删掉手动滚动锁**

现有代码手动设 `document.body.style.overflow = 'hidden'`。antd `Drawer` 自己也会锁。**两套叠加的典型症状是关闭后滚动锁未解除、页面卡死。**

- [ ] **Step 4: 移动端问答面板换 Drawer**

```tsx
{isMobile && (
  <Drawer
    placement="bottom"
    open={chatOpen}
    onClose={() => setChatOpen(false)}

    rootClassName="reader-chat-drawer"
```

**安全区处理:** 原来是 `h-[calc(2.75rem+env(safe-area-inset-bottom))]` 让面板底部与底部条严丝合缝(用 `min-h` 会留约 23px 缝)。Drawer 的高度用 `70dvh`,底部条的高度补偿改在 `index.css` 里针对 `.reader-chat-drawer` 写:

```css
  .reader-chat-drawer .ant-drawer-content-wrapper {
    bottom: calc(2.75rem + env(safe-area-inset-bottom));
  }
}
```

**这个数值必须和底部条的实际高度一致。** 实现时读一遍底部条的 class 确认,不要照抄本计划的数字。

- [ ] **Step 5: 逐条保住 7 项行为**
